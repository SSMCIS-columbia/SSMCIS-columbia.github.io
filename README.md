# SSMCIS-columbia.github.io

## Purpose

Preserving the history of the Secondary School Mathematics Curriculum Improvement Study (SSMCIS), and its history in Haifa, Israel as the "Columbia Program".

---

This repository exists to preserve the narrative and the original project documents in a stable, readable, and hopefully longlasting form.

Thus, an intentionally minimal setup, as a static site.

---

## Structure

- `index.md` — main essay
- `about/` — context
- `assets/` — styles, images, fonts
- `docs/` — generated site (served via GitHub Pages)

---

## Build

The site is built locally using Eleventy.

```bash
npx @11ty/eleventy
```

This writes the static site to `docs/`.

---

## Notes

- The published site is plain HTML/CSS.
- Fonts and assets are self-hosted.
- The setup is designed to require minimal maintenance.
